Лето в удмуртской деревне — v0.32, сборка для тестирования (07.11.2026)

Запуск: распаковать архив целиком и открыть index.html. Для публикации на GitHub Pages загрузить файлы из этой папки в корень репозитория.

Включены главы 1–4, словарь, тренировки «Найди пару» (3 раунда по 3 пары) и «Собери слово», сюжет главы 4 с вопросами «Мар та?», «Кытын?», «Кин та?», конструкциями «Мынам / Тынад» и командами «Шедьты».

В v0.32 добавлено локальное сохранение сюжетного прохождения с кнопкой «Продолжить с сохранённого места», исправлены экраны повторения после глав 2 и 3, обновлена подпись версии.

ОГРАНИЧЕНИЯ: сцены 5–7 главы 4 пока используют временную панораму Вужгурта. Полный проход в Safari не проверен автоматически. Сохранения хранятся в браузере конкретного устройства; режим инкогнито/локальный file:// может ограничивать хранение. Для коллег лучше публиковать через HTTPS.

Для отзыва: проверить обе ветки выбора героя, словарь после новых слов, задания на составление, 3 раунда сопоставления, экраны завершения глав, перезагрузку и продолжение игры.

Исправление v0.32: карточка слова «корка» теперь показывает деревянный дом вместо бабушки.
Для GitHub Pages загрузите содержимое архива в корень репозитория, сохранив папку assets.
